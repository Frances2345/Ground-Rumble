# Controles

| Acción | Input | Notas |
|---|---|---|
| Mover | WASD | Movimiento relativo a cámara |
| Correr | Shift (hold) | Consume stamina |
| Agacharse | Ctrl (toggle) | Reduce altura y velocidad |
| Interactuar | Click | Recoger / presionar |
| Mantener | Click alterno (hold) | Agarrar / sostener |
| Pausa | Esc | Menú de pausa |

## Reglas
- No hay salto en el diseño actual.
- La interacción usa raycast desde la cámara.
